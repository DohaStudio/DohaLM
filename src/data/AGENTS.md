# 데이터 영역 작업 규칙

루트 `AGENTS.md`와 함께 적용한다.

- 원본 데이터는 직접 수정하거나 덮어쓰지 않는다.
- dataset registry에서 목적에 맞게 승인된 데이터만 사용한다.
- 출처·라이선스·사용 조건이 불명확한 데이터는 사용하지 않고 격리·보고한다.
- 원본과 모든 파생 산출물을 checksum·fingerprint·manifest 및 처리 버전으로 연결한다.
- split 전에 exact·near duplicate의 그룹을 구성하고 같은 그룹이 서로 다른 split에 걸치지 않게 한다.
- 학습·검증·테스트 분리와 평가 데이터 누수를 검사한다.
- 개인정보·민감정보·유해 콘텐츠 후보는 자동 사용하지 않고 격리해 승인 절차로 보낸다.
- 원본·정제·토큰화 데이터와 기타 대용량 산출물을 Git에 커밋하지 않는다.
- 필터, 중복, 품질, 누수 임계치를 근거 없이 임의 확정하지 않는다.
- 데이터 처리 코드를 변경하면 관련 데이터 문서, manifest 계약과 unit·component·누수 테스트를 함께 검토·갱신한다.
- 테스트 fixture와 실제 학습 데이터를 명확히 분리하고 실제 학습 데이터 전체를 테스트에 사용하지 않는다.
- validation/test 데이터를 학습이나 overfit fixture로 사용하지 않는다.
